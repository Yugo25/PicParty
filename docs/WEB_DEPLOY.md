# PicParty を Web で公開して iPhone で使う手順

PicParty は Flutter で作っているので、同じコードから **Web 版** を作れます。
Web 版をインターネット上に置けば、iPhone の Safari で URL を開くだけで使えます。
さらに「ホーム画面に追加」すると、アイコンから全画面で起動する“アプリっぽい”状態になります。

公開先には **Netlify（ネットリファイ）** という無料サービスを使います。
フォルダをブラウザにドラッグ＆ドロップするだけで公開できるので、難しいコマンドは不要です。

---

## 0. まず知っておくこと（今の段階の注意点）

- Supabase のキー（`.env`）を使わずにビルドすると、アプリは **Demo Mode**（デモモード）で動きます。
  - データ（作ったパーティ・追加した写真・いいね）は **その端末のブラウザの中だけ** にあります。
  - **ページを再読み込みしたり、アプリを閉じたりすると消えます。**
  - 友達が同じ URL を開いても、**お互いの写真は見えません**。
- `.env` を使ってビルドすると（1. を参照）、最初に **ログイン画面** が出て、自分のアカウントを作れます。
  パーティ・写真・いいね・コメントは友達と共有されます。
  Supabase の準備は `docs/SUPABASE_SETUP.md` を見てください。
- 公開した URL を知っている人は **誰でも開けます**。今はデモデータだけなので問題ありませんが、覚えておいてください。
- プッシュ通知は Web 版では動きません。

---

## 1. Web 版を作る（ビルド）

Mac の「ターミナル」で、次のコマンドを順番に実行します。

```bash
cd ~/PicParty
flutter pub get
flutter build web --release --dart-define-from-file=.env
```

> `--dart-define-from-file=.env` は「Supabase につなぐ」という意味です。`.env` をまだ作っていない場合は、この部分を消して実行するとデモモードになります。

最後に `✓ Built build/web` と表示されれば成功です。
`PicParty/build/web` というフォルダの中に、公開用のファイル一式ができています。

> 初回は 1 分ほどかかります。途中で「Wasm dry run findings」などの英語が出ても、最後に `✓ Built` と出ていれば問題ありません。
> まれに 1 回目だけ「Failed to compile」と出ることがあります。その場合はもう一度同じコマンドを実行してください。

---

## 2. （任意）公開前に、自宅の Wi‑Fi で iPhone から試す

インターネットに公開する前に、手元で動作を確かめられます。

1. ターミナルで次を実行します（実行中はターミナルを閉じないでください）。
   ```bash
   cd ~/PicParty/build/web
   python3 -m http.server 8080
   ```
2. 別のターミナルで Mac の IP アドレスを調べます。
   ```bash
   ipconfig getifaddr en0
   ```
   `192.168.0.121` のような数字が出ます。
3. **Mac と同じ Wi‑Fi に繋いだ iPhone** の Safari で `http://(さっきの数字):8080` を開きます。
   例：`http://192.168.0.121:8080`
4. 終わったら、最初のターミナルで `control + C` を押してサーバーを止めます。

---

## 3. Netlify に無料登録する（最初の 1 回だけ）

1. Mac のブラウザで https://app.netlify.com/signup を開きます。
2. 「**Sign up with GitHub**」を選ぶのが一番簡単です（GitHub アカウント Yugo25 でログイン）。
   メールアドレスで登録しても OK です。
3. 途中で「チーム名」「使い道」などを聞かれたら、適当に入力・選択して進めて大丈夫です（個人利用・無料プランのままで OK、クレジットカードは不要）。

> ⚠️ **必ずログインしてから** 次の手順に進んでください。
> ログインせずにアップロードすると、公開したサイトが **1 時間で消えてしまいます**。

---

## 4. ドラッグ＆ドロップで公開する

1. ログインした状態で https://app.netlify.com/drop を開きます。
   （ダッシュボードの「Add new project」→「Deploy manually」からでも同じ画面に行けます）
2. Finder で `PicParty/build/web` フォルダを開いておきます。
   ターミナルで `open ~/PicParty/build` と打つと、`build` フォルダが開きます。
3. **`web` フォルダごと** を、ブラウザの「Drag and drop your project folder here」と書かれた枠の中にドラッグして離します。
   - `build` フォルダではなく、その中の **`web` フォルダ** です。
4. 数十秒でアップロードが終わり、`https://〇〇〇〇〇.netlify.app` のような URL が表示されます。これがあなたの PicParty の URL です 🎉

### URL を分かりやすい名前に変える（任意）

初期の URL はランダムな英単語です。変更するには：

1. 公開したプロジェクトの画面で「**Project configuration**」（または「Site configuration」）を開く
2. 「**Change project name**」（または「Change site name」）を押す
3. 例えば `picparty-yugo` と入力して保存 → URL が `https://picparty-yugo.netlify.app` になります
   （他の人に使われている名前は使えません）

---

## 5. iPhone で開いて、ホーム画面に追加する

1. iPhone の **Safari** で、さっきの URL（例：`https://picparty-yugo.netlify.app`）を開きます。
   - 初回の読み込みは数秒かかります。真っ白な画面でも少し待ってください。
2. 画面下（または上）の **共有ボタン**（四角から上向き矢印が出ているアイコン）をタップします。
3. メニューを下にスクロールして「**ホーム画面に追加**」をタップします。
4. 名前が「PicParty」になっていることを確認して「**追加**」をタップします。
5. ホーム画面に PicParty のアイコンができます。タップすると、Safari のアドレスバーなしの全画面で起動します。

### 友達に使ってもらうには
URL を LINE などで送るだけです。相手も同じ手順で「ホーム画面に追加」できます。
`.env` を使ってビルドした版なら、相手も新規登録すると、お互いのパーティや写真が見えるようになります（デモモードの版では見えません）。

---

## 6. アプリを修正したときの更新方法

コードを変更したら、もう一度ビルドしてアップロードし直します。

1. ターミナルで：
   ```bash
   cd ~/PicParty
   flutter build web --release --dart-define-from-file=.env
   ```
2. Netlify で公開中のプロジェクトを開き、上部メニューの「**Deploys**」を開きます。
3. ページ下の「Need to update your project? Drag and drop your project folder here」の枠に、
   もう一度 **`build/web` フォルダ** をドラッグ＆ドロップします。
4. 数十秒で同じ URL の中身が新しくなります。

> iPhone で古い画面のままの場合は、PicParty を一度完全に閉じてから開き直してください（アプリ切り替え画面で上にスワイプ）。

## 困ったとき

| 症状 | 対処 |
|---|---|
| iPhone で真っ白なまま | 10 秒ほど待つ。だめなら Safari で再読み込み。電波の良い場所で試す |
| 写真を追加しても、再読み込みすると消える | デモモードで動いています。`--dart-define-from-file=.env` を付けてビルドしてください（0. を参照） |
| ログイン画面が出ない | ビルドのときに `--dart-define-from-file=.env` を付けたか確認してください |
| 「写真を追加」でカメラが起動しない | iPhone の「設定」→「Safari」→「カメラ」が「確認」または「許可」になっているか確認 |
| Netlify のサイトが消えた | ログインせずにアップロードした可能性があります。ログインしてから 4. をやり直してください |
| `flutter: command not found` と出る | Flutter がインストールされているか確認（`which flutter`） |
