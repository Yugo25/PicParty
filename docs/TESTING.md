# 1.0 Beta Test Checklist

1. Install on iPhone and Android.
2. Open Home and Discover.
3. Search a Party.
4. Create a Party with a title, category, countdown style, privacy and duration.
5. Open the Party and verify countdown changes every second.
6. Upload a photo from gallery and camera.
7. Like/unlike a post.
8. Open Profile and Settings.
9. Send a local Demo Chat message.
10. Configure Supabase and repeat the flow with a real account.
11. Test LIVE → ENDED boundary and confirm new uploads stop after end time.
12. Test PUBLIC / UNLISTED / PRIVATE access with two real accounts.
